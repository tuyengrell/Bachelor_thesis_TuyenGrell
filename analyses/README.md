# Analyses

Run after the three preprocessing scripts. Text output goes to `results_combined/`.

- `combined_analysis.py` - combined model, H3a-H3c and exploratory task interactions
- `check_h2_role_contrast.py` - target vs distractor intensity contrast
- `check_distractor_intensity_valence.py` - distractor intensity split by target valence
- `check_selection_bias_h3a.py` - selection check for H3a
- `check_intensity_boundary.py` - cutoff, slope and boundary-picture checks
- `check_intensity_interactions.py` - target intensity by congruency and valence
- `power_analysis_target_intensity.py` - analytic and simulated power 
- `check_intensity_replication.py` - target intensity contrast in all three tasks
- `check_crosstask_picture_rt.py` - picture-level RT correlations across tasks
