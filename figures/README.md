# Figures

Output goes to `thesis_figures/`.

- `thesis_stimulus_distribution.py` – valence norms of the stimulus set (Fig. 3.1)
- `thesis_plots.py` – main effects, model coefficients and combined figures
  (Figs. 4.1, 4.2, 4.4, 4.5, 4.7, 4.8); needs the model output of `CuedAAT/` and `DualPictureTask/`
- `thesis_boundary_pictures.py` – the six pictures at the rounding boundary (Fig. 4.10)

Figs. 3.5, 3.6, 4.3 and 4.6 are written by the task scripts, Figs. 4.9 and 4.11 by `analyses/`.
